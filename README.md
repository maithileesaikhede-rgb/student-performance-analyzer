 # Student Performance Analyzer
 
🚀 Live Demo: student-performance-analyzer ∙ main ∙ app.py

A beginner-friendly Data Science project that analyzes
student marks and presents results in an interactive dashboard.

## Features
- Student marks analysis
- Total and average calculations
- Grade and pass/fail classification
- Subject-wise performance charts
- CSV upload and analyzed results download
- Input validation

## Tech Stack
- Python
- Pandas
- Streamlit
- Plotly

## Run Locally

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the dashboard:

   streamlit run app.py

## Dataset
The project includes sample student marks.
The sample data is illustrative, not real student data.

- Data loading and cleaning
- Descriptive statistics
